O catálogo da interface referencia o acervo institucional fornecido no pacote `ESPA_Atualizacao_Completa_11SET26.zip`.

Documentos confirmados no pacote: GPO-FEV24; Anexos 01, 02, 03, 04, 05, 06, 07, 08 e 08A; Manual da Fauna Silvestre Brasileira; Manual de Combate ao Tráfico de Animais Silvestres/CNMP 2024; Portarias CFA 16/2017 e CFB 01/2024; Modelo Institucional de Resenha Policial.
